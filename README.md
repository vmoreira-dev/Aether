# Aether

Financial insights dashboard for tracking spending, analyzing categories, and optimizing credit-card rewards.

---

## Overview

Aether delivers a streamlined finance interface focused on clear data visualization and efficient analysis.  
It helps users understand their spending patterns, review category trends, and identify the best card to use for each purchase based on reward structures.

## Live Demo

aether.vmoreira.dev

## Stack

- Next.js  
- TypeScript  
- Tailwind CSS  
- Shadcn UI  
- Prisma  
- PostgreSQL  
- Recharts  

---

## Features

- Upload transactions via CSV with automatic parsing  
- Category detection and editable classifications  
- Monthly spending charts and trend analysis  
- Reward optimization engine for credit-card usage  
- Detailed card profiles with reward structures  
- Responsive UI with modular components  
- Clean code structure for easy expansion
