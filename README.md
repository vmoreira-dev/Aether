# Aether

![Aether — Financial Dashboard](./public/assets/aether_5_4.png)


---


## Overview

Aether is a personal finance dashboard focused on isolating signal from financial data.

[Live Demo](https://aether.vmoreira.dev)


---


## Design

- Dark, muted colors with soft contrast
- Panels have a glass-like surface with light blur
- Motion is subtle and only appears when data changes



---

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
