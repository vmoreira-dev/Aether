# Aether

<img width="1024" height="1024" alt="Aether Dashboard" src="https://github.com/user-attachments/assets/4cbab3d8-b4ef-4172-b6ce-355150e9d6ab" />

Financial insights dashboard built to track spending, analyze categories, and optimize credit-card rewards with clarity and precision.

---

## Overview

Aether provides a streamlined finance interface focused on clear visualizations and efficient analysis.  
It highlights spending patterns, category trends, and the optimal card to use for each purchase based on reward structures.

---

## Live Demo

**https://aether.vmoreira.dev**

---

## Stack

- **Next.js**  
- **TypeScript**  
- **Tailwind CSS**  
- **Shadcn UI**  
- **Prisma**  
- **PostgreSQL**  
- **Recharts**

---

## Features

- CSV transaction upload with automatic parsing  
- Editable category detection  
- Monthly spending charts and trend breakdown  
- Credit-card reward optimization engine  
- Detailed card profiles with reward structures  
- Fully responsive layout  
- Modular, scalable codebase
