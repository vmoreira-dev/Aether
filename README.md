# Aether

![Aether — Financial Dashboard](./public/assets/aether_5_4.webp)
Personal finance dashboard focused on spending behavior and signal clarity.
---

## Overview

Aether is a personal finance dashboard focused on isolating signal from financial data.

[Live Demo](https://aether.vmoreira.dev)

---

## Focus

- Spending patterns over time  
- Category concentration and drift  
- Credit-card reward efficiency  

---

## Stack

- Next.js  
- TypeScript  
- Tailwind CSS  
- Prisma ORM  
- PostgreSQL  
- Recharts
